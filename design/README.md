# You Lead Egypt — slideshow lab (in progress)

A 35-minute interactive lab for **middle school**, companion to The Allocation. Students play four
real Egyptian presidents (Nasser, Sadat, Mubarak, Sisi) and make four real decisions, learning all
three density types through Egypt's actual history and culture.

**The deliverable is `../handouts/You-Lead-Egypt-Build-Spec.docx`** — the full build spec, written
to be handed to Claude Design. It carries the design direction, all 19 slides of copy, the density
dashboard figures, the printable advisor cards, and sources.

The two `.dc.html` files here are a partial first pass kept for reference — the copy and layout are
sound, but the canvas was not finished. Build from the spec, not from these.

## Verified figures used throughout

| Year | People | Farmland (sq mi) | Arithmetic | Physiological |
|---|---|---|---|---|
| 1950 | 21.1M | 10,800 | 55 | 1,950 |
| 1970 | 34.5M | 13,100 | 89 | 2,629 |
| 2000 | 68.8M | 12,700 | 178 | 5,402 |
| Today | 116.5M | 10,800 | 301 | 10,780 |

The Aswan dam genuinely added farmland; physiological density rose anyway, because population grew
faster. Today's farmland is roughly the same size as before the dam — desert gains offset by Delta
farmland lost to Cairo's sprawl.
