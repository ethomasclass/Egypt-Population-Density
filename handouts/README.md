# Printable handouts

| File | Who it's for | Pages |
|---|---|---|
| `The-Allocation-Lab-Guide.docx` | Students, one per pair | 5 |
| `The-Allocation-Answer-Key.docx` | Teacher only | ~3 |

Both are editable Word documents — change the questions, drop a round, or re-brand the header,
then print. US Letter, 0.75" margins.

The guide mirrors the app round by round and deliberately does **not** re-collect what the app
already prints. The app's recommendation memo captures allocations, predictions and written
justifications; the worksheet captures what paper does better — long division worked by hand,
rankings, pattern matching, and the concept questions.

Rebuild after editing the source scripts: `node worksheet.js` and `node key.js` (requires `npm install docx`).
